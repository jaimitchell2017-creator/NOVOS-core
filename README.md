# NOVOS Accounts

NOVOS Accounts is the shared identity system for the NOVOS ecosystem.

## Features

- Create a NOVOS Account
- Sign in with NOVOS
- Supabase authentication
- Persistent login sessions
- Password reset
- NOVOS Account ID
- User profiles
- Connected Apps foundation
- Shared account system for future NOVOS services

## NOVOS Ecosystem

The account system is designed to eventually connect:

- NOVOS OS
- NOVOS Messages
- NOVOS Social
- NOVOS Files
- NOVOS AI
- NOVOS Apps
- NOVOS Email

## Supabase

This website uses the NOVOS Core Supabase project.

Only the browser-safe Supabase publishable key is used.

Never put a Supabase service_role key or secret key into this repository.

## Future

The next stage is building the full "Sign in with NOVOS" authorization system.

External websites will be able to:

1. Click "Sign in with NOVOS"
2. Send the user to NOVOS Accounts
3. Let the user sign in
4. Show requested permissions
5. Let the user approve or deny access
6. Return a secure authorization result to the website

Users will be able to manage connected applications from their NOVOS Account.
